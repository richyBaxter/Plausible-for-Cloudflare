# Security Policy

Please **do not** open public issues for security vulnerabilities.

Report privately to **richard.baxter@gmail.com** with repro steps. You should
hear back within a few days; fixes ship as ordinary releases with credit if
you'd like it.

In scope: anything reachable through the Worker — ingestion (`/api/event`),
dashboard auth/session cookies, the stats API, the MCP server, and the privacy
guarantees (no stored IPs, no cross-day visitor correlation).
